🌐 1. Sinkronisasi GitHub Pages (Data Real-Time)
📘 Cara menyiapkan (sekali saja):
  1. Buat repo baru di GitHub (mis. nilai-kelas-3) — boleh Public (murid bisa membaca) atau Private.
  2. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Atur Repository access = Only select repositories (pilih repo Anda), lalu di Permissions → Contents pilih Read and write. Generate lalu salin tokennya.
  4. Tempel token di kolom atas lalu klik Simpan Token.
  5. Push folder situs ini ke GitHub, lalu aktifkan Pages (Settings → Pages → Branch: main, folder / (root)).
  6. Selesai — nilai yang disimpan guru langsung terbaca murid (otomatis tiap 5 detik).
Catatan: token tidak pernah dikirim ke file repo, hanya disimpan di localStorage browser guru. Untuk repo Private, murid tidak bisa membaca — gunakan repo Public.
